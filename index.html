《商道：大明百业图》隐私政策

更新日期：2026年9月18日  |  生效日期：2026年9月18日

一、引言

《商道：大明百业图》（以下简称"本游戏"）由个人开发者满天星光（TapTap 昵称：满天星光，以下简称"我们"）开发运营。我们深知个人信息对您的重要性，将按照法律法规要求，以最小必要原则处理您的个人信息。

请您在使用本游戏前仔细阅读本政策。您勾选同意或继续使用本游戏，即表示您同意我们按照本政策处理您的相关信息。

二、我们收集哪些信息

1. 游戏本体（单机模式）

本游戏单机玩法不收集、不上传任何个人信息。您的游戏存档仅保存在您的设备本地。

2. TapTap 账号登录

当您使用 TapTap 账号登录时，我们会通过 TapTap SDK 获取您的 TapTap OpenID（匿名化账号标识）、昵称与头像，用于识别您的身份、同步游戏权益。

3. 云存档

当您使用云存档功能时，您的游戏存档内容将上传至 TapTap 服务器存储，用于在您更换设备后恢复进度。您可以不使用云存档，此时存档仅保存在本地。

4. 广告展示

当您观看游戏内广告时，广告 SDK 为完成广告投放与计费，可能收集设备标识信息（如 OAID 等匿名设备标识）、设备参数及广告交互记录。我们不将广告数据与您的游戏身份关联用于画像。

5. 成就与礼包

使用成就、礼包功能时，我们通过您的账号标识记录成就进度与礼包领取状态。

三、我们如何使用信息

上述信息仅用于：实现账号登录与权益同步、提供云存档与成就服务、展示广告并计费、处理您的反馈与申诉。我们不将您的个人信息用于与本游戏运营无关的目的。

四、信息存储

您的个人信息存储于中华人民共和国境内的 TapTap 服务器及本设备本地。我们仅在为您提供服务所必需的期限内保存信息；您注销账号或删除存档后，我们将按法律规定删除或匿名化处理。

五、对外共享与第三方 SDK

我们不向任何第三方出售您的个人信息。本游戏接入的第三方 SDK 如下：

SDK 名称使用目的可能收集的信息
TapTap SDK（登录/云存档/成就/礼包）账号登录、云存档、成就与礼包服务OpenID、昵称、头像、存档内容
TapTap 广告组件展示激励/插屏广告并计费匿名设备标识（OAID 等）、设备参数、广告交互记录

第三方 SDK 的信息处理规则以其官方隐私政策为准：TapTap 隐私政策见 TapTap 官网"隐私政策"页面。

六、Cookie 及同类技术

本游戏不使用 Cookie 及同类跟踪技术。

七、信息安全

我们采取传输加密、访问控制及发布前安全加固等措施防止信息泄露、损毁或丢失。如发生个人信息安全事件，我们将依法及时告知您并采取补救措施。

八、您的权利

按照相关法律法规，您享有以下权利：

  • 查询、更正、删除：您可在游戏内或通过下方联系方式查询、更正、删除您的相关信息；
  • 撤回同意：您可在设备系统设置中关闭相应权限，或停用登录/云存档/广告功能；
  • 注销账号：您可通过 TapTap 账号注销流程注销账号，或通过下方联系我们处理；
  • 本地数据清除：卸载游戏即删除设备本地的全部游戏存档数据。

我们将在核实您的身份后于 15 个工作日内响应您的请求。

九、未成年人保护

本游戏主要面向成年用户。若您是未满 14 周岁的未成年人，请在监护人陪同下阅读本政策，并在征得监护人明确同意后使用本游戏；如我们在不知情的情况下收集了未成年人的个人信息，将设法尽快删除。

十、政策更新

因功能调整（如新增联机对战等联网服务）或法律法规变化，我们可能适时更新本政策，并在游戏内或本页面公布。重大变更时我们会以显著方式提示您。
